# Goal Tracker Privacy Policy

Effective date: 30 August 2026

Goal Tracker is developed by Chaowalit Greepoke. This policy explains how the
Android app handles information.

## Data handling

Goal Tracker does not collect, transmit, sell, or share personal information or
other user data. The app does not include accounts, advertising, analytics,
tracking, or app-managed cloud synchronization.

Information entered into the app—including goal titles, notes, categories,
target dates, progress, and creation timestamps—is stored in the app's local
preferences on the user's device. Android application backup is disabled for
this data.

## Crash reports

Builds that are compiled with a Sentry key send a crash report to Sentry
(Functional Software, Inc., United States) when the app hits an unexpected
error. A report contains the error type, where in the app's code it happened,
the app version and basic device information (operating system and model). It
never contains goal titles, notes or any text you typed, error messages,
account or user identifiers, screenshots, or a list of what you did before the
crash. Builds without the key, which includes every build distributed so far,
send nothing. In those builds the app makes no network calls.

## Permissions and third parties

The production app does not request access to location, contacts, photos,
camera, microphone, or other sensitive device data. It does not use a third
party service to process goal data; the only third party is Sentry, for the
crash reports described above.

## User control and deletion

Users can edit or delete an individual goal in the app. They can also remove
all goal data from Settings by choosing **Clear all goals**. Uninstalling the
app removes its local app data according to Android's normal behavior.

## Children

Goal Tracker is a general productivity tool and is not designed specifically
for children.

## Changes

If the app's data practices change, this policy and the Google Play Data safety
declaration will be updated before the changed version is distributed.
